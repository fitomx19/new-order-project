# MathWorld: Guerra Fría 2026

MathWorld es un videojuego de estrategia por turnos para una persona. Gobiernas una superpotencia ficticia y compites con otras dos mientras manejas la economía, las relaciones exteriores y el apoyo al gobierno. La primera prueba se llama *Elecciones bajo apagón* y dura tres turnos. La campaña completa está pensada para el navegador y para partidas de 15 a 18 minutos.

## Para qué hago este proyecto

MathWorld es mi proyecto de portafolio. Quiero mostrar cómo aplico ciencia de datos, ingeniería de software, desarrollo con AWS y agentes de IA para construir un producto que se pueda jugar, probar y revisar.

- **Ciencia de datos.** Modelaré la economía y las elecciones, compararé estrategias por simulación y dejaré los datos, supuestos y semillas para repetir los experimentos.
- **Ingeniería de software.** Construiré el motor, la API y el tablero web. Mostraré cómo se guardan las partidas y cómo se prueban las reglas.
- **AWS.** Integraré el juego y las simulaciones por lotes con un emulador de AWS. Documentaré cómo levantar el entorno desde cero con infraestructura como código. La elección del emulador y los servicios sigue abierta.
- **Agentes de IA.** Crearé un asesor que use datos y pronósticos del juego. Evaluaré si recomienda acciones válidas, explica sus riesgos y respalda sus cifras.

## Cómo seguir la planeación

En la hoja **Plan**, cada fila es una tarea. Ahí puedes ver a qué hito, objetivo y subobjetivo pertenece, cuándo empieza y termina, qué tarea debe quedar lista antes y qué conviene tener en cuenta. Usa la hoja **Hitos** para revisar qué resultado se espera de cada etapa y **Decisiones** para guardar los acuerdos y el motivo de los cambios.

El calendario es una propuesta editable del 23 de noviembre de 2026 al 31 de mayo de 2027. Calcula trabajo de lunes a viernes, en secuencia y sin descontar días festivos. La expansión posterior a la publicación tiene fechas tentativas.
